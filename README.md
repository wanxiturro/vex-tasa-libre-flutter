## ¿Qué es Vex?
Vex es una aplicación para `android & iOS` gratuita que te permite consultar al instante las principales tasas de cambio en Venezuela:

- 💵 Dólar BCV — Tasa oficial del Banco Central de Venezuela
- 💶 Euro BCV — Tasa oficial del euro
- 🪙 USDT — Tasa del dólar digital (Tether)
  
El proyecto original ha sido creado con Next.js y usa PWA para poder instalarlo en móvil, lo puedes encontrar y apoyar [aquí](https://github.com/solamentepuerta/open-cambio).

## ✨ Funcionalidades

- 📈 Dólar BCV, Euro BCV y USDT en tiempo real.
- 🔄 Conversor de divisas integrado.
- ⭐ Tasas personalizadas (guarda tus propias tasas).
- 📡 Múltiples fuentes con fallback automático.
- 🌙 Diseño oscuro y minimalista.

## 🛠️ Instalación en local
```bash
# Requisitos: Flutter 3.35
git clone https://github.com/wanxiturro/vex-tasa-libre.git
cd vex-tasa-libre
flutter pub get
flutter run
```
